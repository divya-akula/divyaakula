## Tools and Services Used

This site and its content are developed with the assistance of the following Microsoft tools and services. Usage of these
tools is subject to their respective licensing and consumption terms, which may change over time. Always verify current
documentation before making architecture or cost decisions.

### GitHub Copilot Harness (Copilot Credits)

Content and agents developed using the **GitHub Copilot Harness** in Copilot Studio consume **Copilot Credits**.

Key points:
- Agents, workflows, and triggers running in the GitHub Copilot Harness each consume Copilot Credits.
- Even a single workflow trigger counts as a Copilot Credit usage event.
- Credits are tied to the GitHub Copilot subscription (Individual, Business, or Enterprise).
- Usage rates evolve; validate current pricing at [GitHub Copilot documentation](https://docs.github.com/en/copilot).

The GitHub Copilot Harness is best suited for reasoning-heavy, multi-step, or open-ended agent work where a
goal-oriented execution model is preferred over a fully predefined process flow.

### Standard Harness (Power Platform / Copilot Studio Licensing)

Content and agents developed using the **Standard Harness** in Copilot Studio run within the Power Platform and
Copilot Studio licensing framework.

Key points:
- Agents and workflows operate under the Copilot Studio and Power Platform licensing model.
- Usage is governed by the Power Platform capacity and message limits assigned to the tenant or environment.
- Licensing tiers include per-user plans, per-flow plans, and tenant-level capacity packs.
- Validate current licensing details at [Microsoft Power Platform licensing documentation](https://learn.microsoft.com/en-us/power-platform/admin/pricing-billing-skus).

The Standard Harness is best suited for predictable, process-driven, rule-based workflows where the path,
triggers, and outcomes are well defined in advance.

### Copilot Chat Harness (Microsoft 365 Copilot Licensing)

Agents deployed into the **Copilot Chat Harness** run within the Microsoft 365 Copilot Chat experience.

Key points:
- Requires a Microsoft 365 Copilot license for end users.
- Consumption is governed by the Microsoft 365 and Copilot Chat licensing terms.
- Validate current licensing at [Microsoft 365 Copilot documentation](https://learn.microsoft.com/en-us/microsoft-365-copilot/).

---

> ⚠️ Copilot Credit and licensing rules evolve quickly. The information above is provided as a learning guide.
> Always verify current official documentation before making production architecture or cost decisions.
